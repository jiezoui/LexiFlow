## 一、 项目核心理念与差异化

> 详细规范见：[01-product.md](file:///c:/Users/JieZou/Desktop/AIC/docs/01-product.md) 与 [03-architecture.md](file:///c:/Users/JieZou/Desktop/AIC/docs/03-architecture.md)

### 1. 一句话定位
**一个把“系统性背词书”（不背单词模式）和“真实语料采词”（Language Reactor 模式）合并成同一套记忆调度的多模态英语学习平台。**

### 2. 核心闭环：两个入口，一个引擎
* **入口 A：词书驱动（解决覆盖率）** —— 覆盖 CET4/6、考研、雅思、托福等大纲词汇，解决“考试要背完”的明确边界。
* **入口 B：语境驱动（解决鲜活度）** —— 从看 YouTube/B站视频、英文阅读、网页划词中一键捕获生词及上下文快照（视频ID + 时间戳 + 原句 + 译文）。
* **唯一排期引擎** —— 全部沉淀至 `user_word`，由 **FSRS（Free Spaced Repetition Scheduler）** 算法统一度量与排期，杜绝传统产品中词书与生词本割裂的双重进度条。

### 3. 杀手级交汇点（竞争护城河）
* **例句自产自用（原声反哺）**：背词书时，例句优先从**用户自己看过的视频中提取原句**，并回放原视频作者**那一秒的原声**（非机械 TTS）。
* **正向强反馈**：看视频时，系统自动识别并高亮标出“这句话里有 3 个你正在背的考纲词”。
* **严守非目标（Non-goals）**：坚决不搞社交榜单、不转存下载视频文件、不抄袭商业词书排版、不搞大模型套壳微调。

## 二、 大赛背景与评审偏好深度拆解

### 1. 赛事规格与含金量
* **全称**：第八届全球校园人工智能算法精英大赛 · 算法主题赛（AI+开源）。
* **地位**：**全国普通高校大学生竞赛正式竞赛目录内赛事（白名单赛事）**，在保研加分、评奖评优、国家奖学金评定中认可度极高。
* **联合主办**：全国组委会、江苏软件产业人才发展基金会、江苏省开源生态创新联盟（秘书处：南京大学）。

### 2. 关键赛程与规则
* **初赛截止时间**：**2026 年 10 月 15 日 20:00**（形式审查合规性）。
* **复赛与国赛**：10 月底线上评审，11 月底全国总决赛线下答辩。
* **参赛人员**：在校本硕专科学生，1~3 人组队（不可跨校），限 2 名指导教师。
* **材料硬指标**：
  * 技术报告（PDF，严格 ≤15 页，匿名盲审，严禁透露学校和教师信息）；
  * 演示视频（MP4，3~5 分钟，≤300MB）；
  * 《开源及第三方资源使用清单》（需详细说明许可证、自研边界）；
  * 开放成果代码/工具仓库链接。

### 3. 评分准则拆解（满分 100 分）
* **实现完成度与可验证效果（25分，最高权重）**：系统真实可跑，演示清晰，有对比测试或验证效果。
* **创新性与方案设计（20分）**：非模板复制，具备自主设计的业务闭环。
* **AI 与开源融合（20分）**：开源选型合理、自研边界清晰、说明关键许可义务。
* **开放成果与复用价值（15分）**：产出具有复用价值的代码仓库、插件、工具集或数据集。
* **问题与场景价值（15分）**：解决真实学习痛点，切口明确。
* **材料规范与表达（5分）**：格式严谨、逻辑清晰。

> **评委核心风向标（一票否决/低分项）**：
> 官方严禁“简单调用大模型通用接口、套壳换皮、复制模板”（得 0~6 分）。
> 倡导“**不拼算力、不拼模型大小，拼开源融合深度、小切口真问题与高完成度工程闭环**”。

## 三、 推荐赛道与作品申报定位

### 🎯 推荐赛道：**方向（一）「开源赋能的 AI 应用创新」**

#### 推荐理由
1. **赛题吻合度 100%**：官方明确指引“面向教育学习、日常生活等真实场景，形成智能体、**网页应用**、小程序、**插件**或软件原型”。
2. **场景与交付形式完全贴合**：LexiFlow 采用 **Web 响应式平台 + Chrome 浏览器划词插件** 双重形态，直击外语学习场景，开发成本适度且利于闭环验证。

* 方案 A（强调多模态与语境）：**《LexiFlow：基于开源生态的多模态语境智能学习平台》**
* 方案 B（强调算法与真实语料）：**《基于真实语料反哺与 FSRS 记忆调度的多模态学习系统》**

## 四、 核心贴赛亮点与技术包装（得分武器库）

结合比赛对“AI+开源”的严苛要求，以下 5 个模块是答辩与技术报告中的核心得分点：

### 1. 影子跟读（Shadowing）× 开源语音 AI（多模态视听亮点）
* **场景痛点**：商业语音评测 API 闭源且收费，通用 ASR 缺乏口语发音教学针对性。
* **开源融合**：选用开源端到端语音识别模型（**OpenAI Whisper** 或 阿里开源 **FunASR / SenseVoice**）。
* **自主算法设计**：
  * 浏览器端采集用户跟读音频，调用本地轻量 ASR 服务生成带时间戳的转录结果；
  * 自研**基于 Levenshtein 动态规划的词级对齐算法（Word-level Forced Alignment）**，精准标注**漏读（Omission）、误读（Substitution）、多读（Insertion）**；
  * 综合时长与声学特征输出客观跟读分，并将评分直接反馈至记忆模型。

### 2. 现代记忆算法（FSRS）× 击键动力学与客观行为映射（直击“算法”命题）
* **场景痛点**：传统间隔重复（SM-2/FSRS）高度依赖用户主观反馈（自评“难/易”），主观噪声大，且练习与复习进度割裂。
* **开源融合**：基于 17~19 参数矩阵的开源科学记忆算法 **FSRS（Free Spaced Repetition Scheduler）**。
* **自主算法设计**：
  * **击键动力学映射**：打字默写零退格且极速 $\to$ `Easy`；有退格/超时 $\to$ `Good`；使用首字母提示 $\to$ `Hard`；拼错 $\to$ `Again`。
  * **多模态练习闭环**：打字拼写、听写、影子跟读等产出型练习直接作为 FSRS 状态更新的客观数据源，全自动化更新记忆稳定性（Stability）与可提取性（Retrievability）。

### 3. 开源 770 万条 ECDICT 词典 × 离线词形还原引擎（NLP 工程硬实力）
* **场景痛点**：大模型高频查词延迟高（2s+）、存在幻觉、调用成本高。
* **开源融合**：引入开源词典数据项目 **ECDICT（770万词条，MIT协议）** 作为本地确定性知识库。
* **自主算法设计**：
  * 解析 ECDICT 构词变换规则字段（`exchange`），构建正向与逆向索引倒排表 `dict_form_index`；
  * 实现 **5ms 内将 `running`/`ran`/`better` 精准还原为标准词元 `run`/`good`**，并保留语法标签，兼顾离线高性能与零幻觉。

### 4. 开源神经机翻（LibreTranslate）本地兜底 × 双语字幕对齐（工程自主可控）
* **场景痛点**：依赖公网 API 导致新用户因未配置 Key 无法使用；双语字幕官方切分点不一致容易错位。
* **开源融合**：引入开源神经机器翻译系统 **LibreTranslate**（基于 OpenNMT）作为 Docker 容器本地运行。
* **自主算法设计**：
  * 构建**“腾讯/微软机翻 $\to$ 本地 LibreTranslate 离线兜底”**的容灾降级链，保障系统零配置下双语字幕可用；
  * 自研**“时间区间重叠时长占比（Intersection over Duration）”**字幕归并算法，自动解决中英文时间轴不对齐问题。

### 5. 比赛满分项：15 分“开放成果与复用价值”落地
* **成果一（应用源码）**：全栈模块化代码开源（Spring Boot 3.3 + Vue 3），提供一键 Docker Compose 部署文件。
* **成果二（独立插件）**：Chrome Extension 划词助记插件（以独立扩展形式发布与演示）。
* **成果三（工具资产）**：开源“ECDICT 词形还原索引提取脚本”与“字幕自动对齐分词提取工具”。

## 六、 备战建议与轻量化交付路线

距离 2026 年 10 月 15 日初赛截止，**不需要完成规划中的全部 S1~S9 阶段**，聚焦完成最小高价值闭环即可制胜：

### 阶段一：打通 S1 核心算法底座（约 10~15 天）
1. 完成 ECDICT 词典导入与 `dict_form_index` 词形还原表构建；
2. 移植并验证 FSRS 调度算法，完成打字默写（Typing）对 FSRS rating 的映射；
3. 基于 `lexiflow-preview.html` 快速跑通前端今日任务仪表盘。

### 阶段二：打通 S2 + 影子跟读视频精听闭环（约 10~15 天）
1. 接入 YouTube / 本地双语视频，完成基于 `requestAnimationFrame` 的字幕同步与点词入库；
2. 接入 Whisper / faster-whisper 跑通影子跟读（Shadowing）与词级差异打分；
3. 验证“**在词书里背到刚才视频的原声台词**”这一杀手锏交付场景。

### 阶段三：竞赛材料深度打磨（约 5~7 天）
1. **录制 3~5 分钟演示视频**：按照“真实学习痛点 $\to$ 视频精听采词 $\to$ 影子跟读智能评测 $\to$ 词书原声反向复习 $\to$ FSRS 自动调度”一条龙演示；
2. **撰写 ≤15 页技术报告**：着重绘制系统架构图、数据流图、开源清单与对比测试数据（重点突出与大模型套壳的区别）；
3. **整理开源仓库**：清理敏感信息，补充完善的 README 与 Docker 快速启动脚本。
