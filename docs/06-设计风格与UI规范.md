# 《语脉 · LexiFlow》前端设计风格与 UI 规范指南

> **文档定位**：本规范是《语脉 · LexiFlow》前端页面开发的统一视觉与交互基准，涵盖色彩系统、排版梯度、间距网格、核心组件规范与微交互动效。供前端开发、UI 设计与组件封装查阅。

---

## 1. 核心设计哲学（Design Philosophy）

《语脉 · LexiFlow》的视觉风格定位为：**“现代纸感编辑风（Modern Paper Editorial） × 极简心流主义（Minimalist Flow）”**。

灵感汲取自 **Linear、Notion、Raycast 与 iA Writer** 等顶级生产力工具，核心理念：
1. **拒斥廉价 AI 感**：坚决摒弃泛滥的紫色渐变、大面积粗糙厚重的霓虹发光与幼稚的卡通拟物化元素；
2. **文字与信息至上**：以杂志级文字排版（Editorial Typography）和清晰的层级对比驱动界面，让用户将注意力 100% 聚焦于语言本身；
3. **呼吸感与纸张质感**：以柔和的冷白/暖灰纸感色替代纯冷刺眼的生硬白底，长时间专注阅读不产生视觉疲劳；
4. **全键盘心流驱动**：所有交互控件具备清晰的物理键位映射提示，动效轻盈迅速（200ms 以内），不打断打字与听力节奏。

## 2. 颜色系统与设计令牌（Design Tokens）

系统严格控制主色系数量，采用基于松石绿与纸墨色调的低饱和高阶质感搭配：

### 2.1 调色板定义

```css
:root {
  /* 页面底衬与卡片表面 (Paper & Surface) */
  --paper: #F4F6F2;             /* 全局冷白纸张底色，低刺激 */
  --surface: #FBFCF9;           /* 卡片与浮层表面，温润纯净 */
  --surface-hover: #EEF2EF;     /* 悬浮轻微对比灰 */
  --surface-active: #E4EBE6;    /* 按压激活态底色 */

  /* 文字与墨色 (Ink & Text) */
  --ink: #1D2523;               /* 主文本：极深松墨黑（非死黑 #000） */
  --muted: #6B7671;             /* 次级文本/描述：中性灰 */
  --dim: #A0AAA5;               /* 弱文本/元信息/时间戳：淡灰 */

  /* 品牌灵魂色：森林松绿 (Pine Accent - 代表沉静、专注与生命力) */
  --accent: #1D9384;            /* 主品牌色 / CTA 按钮 / 选中状态 */
  --accent-dark: #126B60;       /* 主色按压态 / 深色标题 */
  --accent-soft: #DCEFEB;       /* 浅绿微衬底 / 高亮标签 */
  --accent-glow: rgba(29, 147, 132, 0.28); /* 聚焦外发光与光晕 */

  /* 任务与韵律辅助色 (Warm Amber - 代表原声脉搏与连击动力) */
  --warm: #D68E5A;              /* 暖杏金：Streak连击天数 / 正在背诵的生词高亮 */
  --warm-dark: #B8703D;         /* 暖金深色态 */
  --warm-soft: #FBF0E7;         /* 暖金柔和底衬 */

  /* 边框与极细分割线 (Borders & Lines) */
  --line: #DCE4DF;              /* 极细分割线，细腻低对比 */
  --line-strong: #C9D5CE;       /* 边框聚焦/强调线 */

  /* 阴影与深度 (Elevation) */
  --shadow-sm: 0 2px 8px rgba(29, 45, 39, 0.04);
  --shadow-md: 0 8px 24px rgba(29, 45, 39, 0.06);
  --shadow-lg: 0 18px 60px rgba(29, 45, 39, 0.08); /* 大卡片高级弥散柔和投影 */

  /* 圆角规范 (Border Radius) */
  --radius-sm: 8px;             /* 标签、微型按钮、按键标签 kbd */
  --radius-md: 14px;            /* 常规按钮、输入框、普通卡片 */
  --radius-lg: 24px;            /* 主视觉 Hero 容器、弹层模态框 */
}
```

### 2.2 状态语义色（Semantic Colors）
* **拼写/跟读完美（Success）**：`#2E8B57`（森林深翠绿）
* **轻度警告/提示（Warning）**：`#E07A5F`（柔和赤土橙）
* **拼错/退格/失误（Error）**：`#E63946`（温和正红，避免刺眼荧光红）
* **AI 增值生成标注（AI Accent）**：`#7C3AED`（柔和紫罗兰，用于标记“AI解析/AI例句”）

## 3. 字体系统与排版梯度（Typography）

排版采用 **“双字体引擎”**，严格区分人文排版与工业数据：

### 3.1 字体家族（Font Family）
* **主文本字体（Display & Body）**：
  `'Manrope', ui-sans-serif, system-ui, -apple-system, sans-serif`
  * 特性：现代几何无衬线字体，开阔的字怀，数字和字母极具呼吸感与辨识度。
* **数据与代码字体（Mono & Metrics）**：
  `'DM Mono', ui-monospace, SFMono-Regular, Menlo, Consolas, monospace`
  * 应用场景：**音标、打字输入框、按键提示 `<kbd>`、时间戳 `00:14.2`、FSRS 参数、天数统计**。

### 3.2 字阶规范表（Type Scale）

| 级别 | 字体 | 字号 (px) | 字重 | 行高 | 字距 (letter-spacing) | 典型应用场景 |
|---|---|---|---|---|---|---|
| **Display** | Manrope | 36 ~ 44 | 800 (ExtraBold) | 1.05 | `-0.055em` | 今日学习概览主标题、大字报 |
| **H1** | Manrope | 24 ~ 28 | 700 (Bold) | 1.2 | `-0.035em` | 模块主标题、视频详情标题 |
| **H2 / Card Title** | Manrope | 17 ~ 20 | 600 (SemiBold) | 1.3 | `-0.02em` | 卡片标题、词书名、设置项标题 |
| **Body (正文)** | Manrope | 14 ~ 15 | 400 (Regular) | 1.65 | `0` | 双语释义、例句译文、文章段落 |
| **Eyebrow / Label** | DM Mono | 10 ~ 11 | 500 (Medium) | 1.0 | `+0.08em` (大写) | 模块副标前缀（如 `TODAY'S MISSION`） |
| **Kbd / Tag** | DM Mono | 10 ~ 11 | 500 (Medium) | 1.0 | `0` | 快捷键徽章 `[Space]`、音标 `[prəˈvoʊk]` |
| **Hero Data** | DM Mono | 28 ~ 32 | 500 (Medium) | 1.0 | `-0.08em` | 待复习数字 `45`、连击天数 `12` |

## 4. 间距与骨架网格规范（Layout & Grid）

采用 **8px 为基准** 的间距倍数体系：
* **微间距**：`4px`（按键内边距）、`8px`（图标与文字间隙）
* **小间距**：`12px`（列表条目间隙）、`16px`（常规卡片内衬 Padding）
* **标准间距**：`24px`（大卡片 Padding、网格间隙 Gap）
* **段落/区块间距**：`36px` ~ `48px`（模块上下呼吸空白）

### 4.1 页面两栏网格（App Shell）
* **左侧边栏（Sidebar）**：
  * 展开宽度：固定 `244px`；
  * 视觉材质：半透明白玻底 `background: rgba(251, 252, 249, 0.84); backdrop-filter: blur(18px);`；
  * 右边框：`1px solid var(--line)`。
* **右侧主工作区（Main Stage）**：
  * 最大内容安全宽度：`1210px` 自动居中；
  * 左右内边距：`clamp(20px, 4vw, 56px)` 自适应。

## 5. 核心 UI 组件视觉规范

### 5.1 按钮体系（Buttons）
* **主按钮（Primary Button）**：
  * 背景：`var(--accent)`（松石绿）；文字：纯白 `#FFFFFF`；
  * 悬浮态：微上浮 1px，投影外溢 `box-shadow: 0 8px 20px rgba(29, 147, 132, 0.28)`；
  * 附带快捷键标记：内部右侧常驻淡绿透明小标签（如 `Space`）。
* **次级按钮（Secondary Button）**：
  * 背景：纯白 `var(--surface)`；边框：`1px solid var(--line)`；文字：`var(--ink)`；
  * 悬浮态：背景变为 `#FFFFFF`，边框变深 `var(--line-strong)`。
* **图标微按钮（Icon Action）**：
  * 尺寸：`36px × 36px` 圆角 `12px`；边框与次级按钮一致，居中渲染 SVG 图标。

### 5.2 快捷键徽章（`<kbd>` 标签）
* **样式**：
  * `font-family: var(--mono); font-size: 10px; font-weight: 500;`
  * `padding: 2px 6px; border-radius: 5px;`
  * 背景：`var(--paper)`；边框：`1px solid var(--line-strong)`；文字：`#8C9791`。

### 5.3 视频双语字幕行（`CueLine`）与高亮三态
* **默认状态**：普通英文字幕文字为深灰，中文译文为次级浅灰；
* **当前播放行（Active Cue）**：
  * 行左侧带一根 `3px` 宽的松绿发光指示条（`border-left: 3px solid var(--accent)`）；
  * 背景变为微微半透明浅绿：`rgba(29, 147, 132, 0.05)`；
* **单词高亮的三种语法层级**：
  1. *未背过的已知词*：默认正常文字；
  2. *生词本中已有词*：底部带有浅黄色平滑虚线下划线；
  3. *当前词书正在背诵的考纲词*：**字重加粗 + 松石绿发光标记（`color: #126B60; background: #DCEFEB; padding: 0 3px; border-radius: 4px;`）**。

### 5.4 打字默写组件（`TypingBox`）
* 居中宽敞卡片，提供大号等宽槽位；
* 光标动效：松绿等宽垂直竖线，每秒轻柔平滑脉动；
* **交互反馈**：
  * 输入正确：字母瞬时转为清晰深绿色（`#2E8B57`）；
  * 输入错误：输入框在 150ms 内发生轻微水平抖动（`transform: translateX(-4px) -> translateX(4px)`），字母瞬时标红并自动清除错误键入。

### 5.5 影子跟读评测对比卡片（`ShadowingDiff`）
* 原文拆解为独立的词块胶囊（Word Chips）：
  * **标准正确**：深绿字体 + 浅绿胶囊衬底；
  * **漏读/吞音（Omission）**：浅灰划线 + 灰色虚线框；
  * **误读（Substitution）**：柔和红字 + 淡红衬底（上方悬浮标注用户实际发音的音标）；
  * **多读（Insertion）**：黄色警示标签。

## 6. 微交互与动效节奏（Motion & Transitions）

* **通用缓动函数**：`cubic-bezier(0.16, 1, 0.3, 1)`（类似苹果 iOS 的极速响应与平滑减速）；
* **持续时间标准**：
  * 按钮悬浮、颜色切换：`150ms ~ 200ms`；
  * 弹层展开、模态框浮现：`240ms`（带 `scale(0.98) -> scale(1.0)` 微缩放）；
  * 播放器字幕跟随高亮：**禁止 CSS 过渡延迟**，采用 `requestAnimationFrame` 驱动瞬时无损变色，确保 60fps 绝对精准同步。

## 7. Tailwind CSS 配置文件（快速接入预设）

前端项目安装好 Tailwind CSS 后，可直接合并如下配置：

```javascript
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        paper: '#F4F6F2',
        surface: '#FBFCF9',
        ink: '#1D2523',
        muted: '#6B7671',
        dim: '#A0AAA5',
        line: '#DCE4DF',
        'line-strong': '#C9D5CE',
        accent: {
          DEFAULT: '#1D9384',
          dark: '#126B60',
          soft: '#DCEFEB',
        },
        warm: {
          DEFAULT: '#D68E5A',
          dark: '#B8703D',
          soft: '#FBF0E7',
        }
      },
      fontFamily: {
        sans: ['Manrope', 'system-ui', 'sans-serif'],
        mono: ['DM Mono', 'ui-monospace', 'monospace'],
      },
      borderRadius: {
        'lg': '24px',
        'md': '14px',
        'sm': '8px',
      },
      boxShadow: {
        'soft': '0 18px 60px rgba(29, 45, 39, 0.08)',
      }
    }
  }
}
```
