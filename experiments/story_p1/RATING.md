# P1 人工盲评操作说明

独立测试完成后，`summarize.py` 从预先指定的 library、journey 两个主题抽出 12 题 × A/B/C 三组，共 36 篇。它生成随机顺序的 `blind_rating_sheet.csv` 和单独保存的 `blind_key_keep_private.csv`。评分前不要让评分者看到映射表、自动指标或算法组名。

请两位熟悉英语学习材料的评分者独立复制盲评表，各自填写 `rater_id` 和四项 1–5 分。每篇都可读目标词、英文正文和中文译文。建议按以下锚点评分：

| 分数 | 自然度、连贯性、目标词使用、译文忠实度的统一锚点 |
| --- | --- |
| 1 | 明显不通顺或多处严重错误，无法用于学习 |
| 2 | 有多处生硬、跳跃、强行用词或误译 |
| 3 | 基本可读，存在少量明显问题 |
| 4 | 通顺且内容连贯，只有轻微问题 |
| 5 | 自然、连贯、目标词融入妥当，译文准确 |

四项分别判断；`notes` 记录具体问题，避免只给总印象。评分者不讨论分数。完成后按 `record_id` 合并两份表并揭盲，报告每组的均值或中位数、评分者分歧，以及具体失败例子。若 C 任一项的双人平均分比 B 低至少 0.5，不宣称整体语言质量改善。若没有实际双人评分，技术报告只能声称自动规则验收结果，不能声称语言质量或学习效果改善。
