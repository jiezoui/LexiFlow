# 影子跟读发音评测对照实验 (Speech Evaluation Benchmark)

本目录记录影子跟读模块的发音评分算法选型依据、多方案基准对照实验与复现流程。

---

## 一、 实验目标与方案设计

针对英语学习者跟读录音，评估不同声学评分器在人工评分真实音频上的打分一致性、绝对误差以及对严重发音错误的诊断敏感度，比较以下三种方案：

| 方案标识 | 算法机制 | 核心原理 |
| :--- | :--- | :--- |
| **A. ASR 词编辑距离** (Baseline) | 纯词级识别基线 | 基于 Whisper ASR 转写结果与参考文本的 Levenshtein 动态规划对齐，无音素级声学特征参与。 |
| **B. CTC Viterbi** (现行默认方案) | 最优路径发射概率对齐 | 在开源 `wav2vec2` 音素 CTC 模型概率输出上，通过自主实现的 Viterbi 动态规划求参考音素的最优合法对齐路径；取所属帧目标发射概率的几何均值映射为声学分。 |
| **C. FB+Rank** (原方案) | 前向—后向状态占用后验 + 排名 | 通过 CTC Forward-Backward 算法计算参考状态占据各帧的后验峰值，并融合该音素在帧内的声学排名。 |

---

## 二、 基准实验结果 (SpeechOcean762)

基于官方测试集（500 条真实学习者录音，覆盖 125 名说话人、9,483 个参考音素），采用数据集官方人工评分与标注进行离线组件对照：

| 评估指标 | ASR 词编辑距离 (基线) | CTC Viterbi (现行方案) | FB+Rank (原方案) | 结论说明 |
| :--- | :---: | :---: | :---: | :--- |
| **Pearson 相关系数 (\(r\))** | 0.4316 | **0.5379** | 0.5316 | Viterbi 与人工分整体相关度略优；两者的 Bootstrap 95% 置信差值为 `[-0.024, 0.011]`。 |
| **句级平均绝对误差 (MAE)** | 19.61 分 | **11.12 分** | 15.91 分 | **Viterbi 显著降低系统性偏差**；原 FB+Rank 对低分录音存在严重高估现象（差值达 44 分）。 |
| **严重音素错误检出 F1** | 0.2567 | **0.3535** | 0.3278 | Viterbi 查准率约为 26.2%、召回率约 54.5%，更能有效捕捉发音薄弱音素。 |

## 三、 产品链路设计与质量门控

为解决生产环境中录音质量低劣或 ASR 假性对齐导致的“伪低分”问题，线上服务引入了以下前置门控：

1. **ASR 提示词隔离**：Whisper 转写时不注入参考文本作为 `initial_prompt`，避免模型强行将漏读词“脑补”进转写结果。
2. **输入音频声学门控**：
   - 裁首尾静音后有效音频 `< 0.25s`：返回 HTTP 422 提示重录。
   - 整体能量 `RMS < -45 dBFS`：提示音量过低。
   - 削波样本比例 `> 5%`：提示麦克风削波失真。
3. **内容匹配度门控**：4 词以上句子与参考句的词级精确匹配率 `< 25%` 时，判定为内容严重偏离，不给出正式分数。
4. **词级降级标记**：当 G2P 或音素模型异常时，显式标记 `word_level_fallback`，不生成伪音素诊断，且不计入今日打卡。

复现环境使用 Python 3.10+，以仓库根目录为起点。

验证 CTC Viterbi 动态规划实现、状态转移合法性、短音频边界与前向—后向数值对拍：
```powershell
& .\speech-bridge\.venv\Scripts\python.exe -m unittest discover -s speech-bridge\tests -p test_assess_v2.py -v
```

### 2. 语音服务端到端冒烟自检
验证模型加载、TTS 合成、音素 G2P 与三维打分接口联通性：
```powershell
& .\speech-bridge\.venv\Scripts\python.exe speech-bridge\selftest.py

```

## 五、 局限性与科学边界

1. **声学概率映射而非生理真值**：所计算的音素分是模型在强制对齐合法路径下的几何均值映射，属于声学证据强度，并非人类听觉发音完全正确的绝对生理概率。
2. **查准率边界**：严重音素错误检出的精确率仍有局限（存在假阳性），因此前端界面定位于“声学证据较弱”，引导用户回听与对比，不武断声称特定替换音素。
3. **启发式权重**：总分中准确度（0.50）、完整度（0.30）、流利度（0.20）为工程加权参数，适合激励学习与趋势追踪，不能直接等同于标准化语言考试（如雅思/托福）分制。
